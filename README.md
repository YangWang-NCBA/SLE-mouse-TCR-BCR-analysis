# Longitudinal blood and multi-organ TCR/BCR sequencing in IMQ-treated mice

This code reproduces Figures 2–4 and Tables 1–4 from the processed study data and the authors’ derived measurements.

## Run

Download `SLE_metadata_QC_PRJCA075761.zip` and `SLE_FastQC_reports_PRJCA075761.zip` into one directory. Use their location in place of `../omix` below. Run the commands from the directory containing `reproduce.py`. [OMIX022213](https://ngdc.cncb.ac.cn/omix/release/OMIX022213)

```bash
conda env create -f environment.yml
conda activate sle-mice-analysis
python reproduce.py --omix ../omix --output results
```

The [Python package snapshot](requirements-freeze.txt) lists the versions used to generate the figures and tables.

Tested on Windows 11 (build 26200), with Python 3.12.14 and R 4.6.1. A complete `reproduce.py --omix` run using the metadata ZIP and locally extracted FastQC statistics took approximately 40 seconds on an Intel Core Ultra 7 255HX computer with 16 GB RAM. This excludes downloads, environment installation and raw-read processing. Environment installation time was not benchmarked.

Once the environment and downloads are available, the analysis runs offline. `--omix` also accepts the metadata ZIP itself or its extracted directory. Metadata schema 2.0 has eight files at its root: `study.json`, `samples.tsv`, `libraries.tsv`, `fastq_qc.tsv`, `chain_records.tsv`, `primers.tsv`, `dictionary.tsv` and `README.md`. Earlier packages containing `metadata/` and `qc_summary/`, including the named `SLE_metadata_QC_PRJCA075761/` wrapper, remain readable. If the FastQC archive or extracted `fastqc/` directory is elsewhere, supply its location with `--fastqc`. Use a new output directory for each run.

`--data-dir` accepts a complete prepared data directory from a previous `--omix` run or upstream recalculation; this route does not reread either OMIX archive. The shipped `data/` directory contains derived inputs and table templates and cannot be used directly with this option. An initial `--omix` run combines those inputs with the deposited metadata and QC. Fig. 2 uses three FastQC tables under the prepared data directory’s `fastqc/` subdirectory; these are generated by an `--omix` run or by `upstream/fastqc_tables.py` from the deposited FastQC archive.

The assembled figures are in `results/fig/assembled/` (vector PDF and 600 dpi PNG). Tables 1–4 are in `results/table/publication/`. For an `--omix` run, the resolved numerical inputs and specimen and library keys are in `results/data/`. The individual R panels retain the analysis typography. The assembly step applies the submitted panel and label layouts to analytical graphics generated by R. The assembly script places the newly calculated R vector graphics using `code/panel_layout.tsv`. The matching axis, strip and legend labels use the font sizes, colours and baselines in `code/label_layout.tsv`. When an input change produces different axis ticks, that panel keeps the labels and positions calculated by R. The reference layout uses Arial Bold. If Arial or its bold face is unavailable, install Liberation Sans (including its bold face) and pass `--font "Liberation Sans"`. Figure 1 and Supplementary Figure 1 are supplied separately with the submission. Each figure also has a `source_data/` directory. Individual records use `SampleID` (collection label) and `tissue` to identify a specimen. [Data columns and units](upstream/README.md#data-columns)

## Data availability

BioProject PRJCA075761 links the raw paired-end reads and the processed data. The OMIX metadata archive supplies the specimen-to-library mapping, export status for each chain, the per-library MiXCR QC fields (from which `mixcr_library_qc.tsv` is reconstructed), and the 23 reverse-transcription and PCR primers used in Table 2 (`primers.tsv`). The reader restores shared fields and derived ratios into the existing analysis input tables; the current metadata archive covers the 875 expected target-chain exports. Its `dictionary.tsv` defines the fields and reconstruction rules. The separate FastQC archive supplies the per-file measurements used in Fig. 2. [GSA CRA051972](https://ngdc.cncb.ac.cn/gsa/browse/CRA051972) · [OMIX022213](https://ngdc.cncb.ac.cn/omix/release/OMIX022213)

The package supplies sequence metrics and abundance ranks, counts of distinct native clone IDs, records with ambiguous chain assignments, and mate-specific SeqKit Q30 percentages. The 11 tissue-specific MiXCR archives are used when recalculating from native exports. [Upstream processing instructions](upstream/README.md)
